# 03 - 泵电机控制状态机

12 V 辅助冷却泵的控制逻辑：预充 → 运行 → 降额 → 故障锁存，保护优先于控制。

## 状态

```
INIT ──100ms──> STANDBY ──cmd>0──> PRECHARGE ──300ms──> RUNNING <──> DERATE
                     ^                                        │
                     └──────── clear + 健康 100ms ──── FAULT <┘
```

## 保护策略

| 条件 | 阈值 | 去抖 | 动作 |
|---|---|---|---|
| 过流 | > 2500 mA | 50 ms | 锁存故障 0x01，切 PWM 与功率级 |
| 欠压 | < 9.0 V | 100 ms | 锁存 0x02 |
| 过压 | > 16.0 V | 50 ms | 锁存 0x03 |
| 过温 | > 120 ℃ | 200 ms | 进入降额，PWM 限 50 % |
| 传感器不可信 | 温度 > 200 ℃ 等 | 立即 | 锁存 0x05 |

- 故障锁存：输入恢复正常也不自动恢复，必须收到 `clear_fault` 且连续 100 ms 健康；
- 降额恢复：温度回落到 110 ℃ 以下并保持 300 ms 才回到运行；
- 指令上限 100 %，PWM 永远不超过指令值。

## 测试

`make test` → 48 项断言，含：
- 启动时序（预充不足 300 ms 不转）、停机回待机；
- 过流去抖（40 ms 不跳 / 60 ms 跳）与锁存、故障清除的三重门控；
- 欠压、过压、过温降额与恢复；
- 传感器开路立即故障；
- **随机故障注入**：4000 步随机传感器序列，断言故障态 PWM 恒 0、PWM ≤ 指令、错误码不越界；
- **集成测试**：CAN 指令帧解码 → 状态机 → 状态帧编码，验证 60 % 指令落到 PWM 60 %。
