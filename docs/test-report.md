## 失效模式对应

| 失效模式 | 是否覆盖 | 对应用例 |
|---|---|---|
| 信号位序搞反 | 是 | Motorola 逐字节布局断言 |
| 超范围值被静默截断 | 是 | 越界拒绝、位宽保护 |
| 长报文丢帧或错序 | 是 | 多帧重组、序号错乱中止 |
| 诊断未授权写入 | 是 | 写 DID 三重门控 |
| 过流保护不动作 / 误动作 | 是 | 去抖窗口双侧断言 |
| 故障后自动恢复（危险） | 是 | 锁存与清除门控 |
| 传感器失效导致误动作 | 是 | 开路立即故障 |
| 输出超过指令 | 是 | 随机注入不变量 |

## 未覆盖与残余风险

- 无 HIL / 台架：时序为软件步进仿真，未验证真实采样抖动、总线负载与中断延迟；
- 未做 MCU 目标编译：没有验证 32 位对齐、栈深度、浮点单元差异；
- 未做 MISRA-C 静态检查与 ASIL 分解，本文档中的风险等级是工程判断，不是认证结论；
- CAN 驱动层（邮箱、错误帧、总线关闭恢复）不在本仓库范围；
- UDS 未覆盖 0x19 / 0x2F / 0x31 / 0x85，安全访问仅为固定种子算法，不具备量产安全性。
