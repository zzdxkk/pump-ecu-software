# 02 - ISO-TP 与 UDS 诊断

诊断链路的两个层次：ISO-TP 负责把长报文拆成 8 字节帧，UDS 负责解释服务与返回码。

## ISO-TP

- 接收：单帧（SF）、首帧（FF）、连续帧（CF），序号 0..15 循环，序号错乱即中止传输；
- 发送：≤7 字节走单帧，否则首帧 + 连续帧；
- 缓冲区定长 64 字节，由调用方分配，无动态内存。

## UDS 服务

| SID | 服务 | 关键行为 |
|---|---|---|
| 0x10 | 会话控制 | 01 默认 / 02 编程 / 03 扩展；离开默认会话清除安全访问 |
| 0x11 | ECU 复位 | 正响应后恢复初始状态 |
| 0x22 | 按 DID 读数据 | F186 当前会话、F190 VIN（17 字节）、F187 零件号 |
| 0x27 | 安全访问 | 种子 0x1234，密钥 = 种子 XOR 0x5A5A；错误密钥返回 0x35 |
| 0x2E | 按 DID 写数据 | 需扩展会话 + 已解锁，否则 0x22 / 0x33 |
| 0x3E | Tester Present | 支持 00 / 80 子功能 |

负响应统一为 `7F SID NRC`，覆盖 0x11 / 0x12 / 0x13 / 0x22 / 0x24 / 0x31 / 0x33 / 0x35。

## 测试

`make test` → 84 项断言：会话迁移与安全访问失效、DID 读取与长度校验、错误密钥与顺序错误、写 DID 的三个前置条件、ISO-TP 单帧/多帧/序号错乱、分段与重组往返、端到端（20 字节请求拆帧 → 重组 → UDS 处理）。
